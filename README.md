## English

### Overview
A per-language index of my working code: Python, Rust and Go. Each directory
holds small, runnable pieces plus a README stating what it is and how to run it.
Larger projects live in their own repositories and are linked from here.

### Layout
| Directory | Language | Status |
|---|---|---|
| [python/](python/) | Python | scaffold |
| [rust/](rust/) | Rust | scaffold |
| [go/](go/) | Go | scaffold |

### Policy
- Every entry says what it does, how to run it, and how it was verified.
- Nothing is listed until it exists in this repository or links to a public one.
